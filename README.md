# 📊 Retail Sales Forecasting & Inventory Optimization System

## 🚀 Project Overview
This project is a machine learning-based system that forecasts retail product sales and optimizes inventory levels using Safety Stock, Reorder Point, and demand prediction techniques.

It helps simulate real-world retail operations like supermarkets and e-commerce platforms.

---

## 🎯 Problem Statement
Retail businesses often face:
- Stockouts (lost sales)
- Overstocking (increased cost)
- Poor demand forecasting

This system solves these problems using data science and inventory optimization techniques.

---

## 🧠 Solution Approach
- Data preprocessing
- Exploratory Data Analysis (EDA)
- Sales forecasting model
- Inventory optimization logic
- Safety Stock & Reorder Point calculation
